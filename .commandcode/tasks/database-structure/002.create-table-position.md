- Import `defaultColumn` from `../utils/default-columns`
- Import `departments` from `./departments`
- Define and export `positions` table with columns:

  - `name` — varchar(100)
  - `isHod` — boolean, default false
  - Spread `...defaultColumn` for audit/soft-delete columns
